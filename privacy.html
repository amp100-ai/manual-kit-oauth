プライバシーポリシー

「manual-kit スプシ読み取り」（以下「本ツール」）は、社内の担当者が使う業務ツールです。本ツールが Google のアカウントから受け取る情報と、その扱いは次のとおりです。

制定日: 2026年10月1日 ／ 改定日: 2026年10月6日（マニュアルを Google スライドとして置く機能を足しました）

1. 受け取る情報

  • Google スプレッドシートの中身（読み取りのみ。権限 spreadsheets.readonly）
  • Google ドライブのファイルの情報（ファイル名・更新日時・版の番号など。中身は含みません。権限 drive.metadata.readonly）
  • 本ツールが作った Google スライドのファイル（権限 drive.file。本ツールが作ったファイルだけを扱えます）

読み取れるのは、担当者が許可した Google アカウントで開けるファイルだけです。

2. 使い方

  • 担当者が指定したスプレッドシートを読み取り、担当者自身のパソコンに CSV として保存するために使います
  • 担当者が作ったマニュアル（PowerPoint のファイル）を Google スライドに変換し、担当者が指定した、または担当者のパソコンの置き場所から探したフォルダに新しく作るために使います。作った後、変換できたかを確かめるために、そのファイルを PDF として担当者のパソコンに保存します
  • 本ツールが作ったファイルのほかは、書き換えたり、削除したりはしません
  • 広告、ほかの目的での分析、機械学習モデルの学習には使いません

3. 保存と第三者への提供

  • 読み取った内容と、Google から受け取った許可の情報（トークン）は、担当者自身のパソコンにだけ保存します
  • 本ツールの作成者や、そのほかの第三者のサーバーには送りません
  • 法令で求められる場合を除き、第三者に提供しません

4. Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の使用と、ほかのアプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

5. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。あわせて、担当者のパソコンに保存された許可の情報（token.json）を削除してください。
